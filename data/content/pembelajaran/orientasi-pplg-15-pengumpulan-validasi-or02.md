Hari yang dinantikan telah tiba! Pada **Pertemuan 15**, kalian secara resmi mengumpulkan mahakarya Sprint 2 kalian: **Dokumen Laporan Review Produk Digital Lengkap (Evidence Utama Skill Passport OR-02)**.

## 🎯 Rubrik Resmi Penilaian Skill Passport OR-02

| Aspek Penilaian | Level 1 (Mengenal) | Level 2 (Mencoba ★ Target) | Level 3 (Mandiri) | Level 4 (Mahir / Portofolio) |
| :--- | :--- | :--- | :--- | :--- |
| **Kelengkapan 6 Komponen** | Kurang dari 4 komponen terisi. | 6 komponen terisi walau deskripsi masih ringkas. | 6 komponen terisi lengkap, detail, dan terstruktur rapi. | Sangat lengkap, mendalam, disertai referensi standar industri. |
| **Analisis Fungsionalitas** | Tidak menjelaskan fungsi sistem. | Fungsi dijelaskan secara umum. | Fungsi utama jelas disertai alur kerja (*user flow*) terinci. | Analisis mendalam dengan skenario pengujian kasus nyata. |
| **Analisis UI & UX + Bukti Visual** | Hanya opini tanpa bukti visual sama sekali. | Ada observasi tampilan, bukti visual minim (1 screenshot). | Observasi tajam disertai 2-3 screenshot ber-anotasi penjelas. | Analisis komprehensif, komparasi mockup, visual beresolusi tinggi. |
| **Rekomendasi Solutif Developer** | Tidak ada saran solutif. | Saran ada namun terlalu umum (*"tingkatkan lagi"*). | Saran konkret, logis, dan dapat diterapkan oleh programmer. | Solusi sangat teknis, terinci, dan mempertimbangkan UX & bisnis. |

## 📋 Prosedur Pengumpulan Evidence OR-02

Ikuti langkah-langkah pengumpulan berikut secara disiplin:
1. **Periksa Nama File:** Pastikan file PDF kalian bernama: `[NIS]_[NamaLengkap]_OR-02_ReviewAplikasi.pdf`.  
   *(Contoh: `252610015_CitraLestari_OR-02_ReviewAplikasi.pdf`)*
2. **Upload ke Google Drive:** Unggah ke folder `📁 Skill_Passport_RPL/OR-02/`.
3. **Set Akses Publik:** Klik kanan file di GDrive ➔ *Share* ➔ Ubah *General Access* menjadi **"Anyone with the link can view"**.
4. **Klaim Penyelesaian:** Masukkan link file ke lembar rekapitulasi kelas / submit modul ini.

## ⚡ Langkah Selanjutnya: Aktivitas Belajar

Gunakan tab di bagian atas modul ini untuk menyelesaikan tahapan belajar kalian:

1. 📖 **Tab 1 (Materi & Checkpoint)**: Pelajari materi lalu tuntaskan kuis checkpoint tiga tahap agar Tab 2 terbuka.
2. 📝 **Tab 2 (Form LKPD Interaktif)**: Isi dan kirim LKPD secara mandiri; sertakan URL Google Drive portofolio bila diperlukan agar Tab 3 terbuka (+25 XP).
3. 💭 **Tab 3 (Jurnal Refleksi)**: Tulis dan kirim refleksi mandiri (+15 XP), kemudian klik **“Tandai Selesai & Buka Modul Selanjutnya”** untuk menuntaskan modul.
4. 🎯 **Tab 4 (Panduan Kriteria Guru)**: Gunakan matriks KKTP untuk memeriksa target karya kalian.
