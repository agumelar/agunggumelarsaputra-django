# 8 Profesi Utama & Sinergi Tim Industri PPLG

Ketika kalian memesan makanan lewat aplikasi *Gojek*, berbelanja di *Tokopedia*, atau bertanding di *Mobile Legends*, aplikasi-aplikasi tersebut tidak pernah dibuat oleh satu orang saja. Di balik satu aplikasi canggih, terdapat **Tim Produk Digital** yang terdiri dari beragam profesional dengan spesialisasi tugasnya masing-masing.

Modul ini mengupas tuntas **8 Profesi Utama di Industri PPLG** beserta tanggung jawab, bahasa pemrograman, tools kerja, dan bagaimana mereka bekerja sama dalam satu kesatuan sistem.

### 1. Frontend Developer (Pengembang Antarmuka Web)
- **💡 Analogi**: *Desainer Interior & Kasir Toko* — Menyiapkan bagian ruangan yang dilihat, disentuh, dan diinteraksikan langsung oleh pengunjung.
- **Tugas Utama**: Mengubah desain visual dari UI Designer menjadi kode website yang interaktif, responsif di HP/laptop, dan cepat dimuat.
- **Bahasa & Tools**: HTML5, CSS3, JavaScript, TypeScript, React.js, Tailwind CSS, Vue.js, VS Code.
- **Contoh Hasil Karya**: Tampilan halaman beranda Tokopedia, formulir registrasi online, animasi tombol dashboard.

---

### 2. Backend Developer (Pengembang Server & Logika Bisnis)
- **💡 Analogi**: *Koki Dapur & Manajer Gudang* — Bekerja di balik layar yang tidak terlihat pengunjung, namun memproses pesanan, memasak data, dan mengamankan brankas.
- **Tugas Utama**: Mengatur server, membuat API (*Application Programming Interface*), memproses logika transaksi pembayaran, serta mengelola basis data (*database*).
- **Bahasa & Tools**: Node.js, Python, PHP, Golang, Java, PostgreSQL, MySQL, Redis, Postman.
- **Contoh Hasil Karya**: Sistem verifikasi password, algoritma penghitungan ongkir Gojek, sistem pemotongan saldo e-wallet.

---

### 3. Mobile App Developer (Pengembang Aplikasi HP)
- **💡 Analogi**: *Montir Mobil Portabel* — Membangun kendaraan mini yang siap melaju mulus di berbagai jenis sasis smartphone (Android & iOS).
- **Tugas Utama**: Merancang dan memprogram aplikasi yang diinstal langsung di smartphone, mengoptimalkan konsumsi baterai, memori, dan sensor kamera/GPS.
- **Bahasa & Tools**: Kotlin, Java (Android Native), Swift (iOS Native), Flutter (Dart), React Native.
- **Contoh Hasil Karya**: Aplikasi WhatsApp di PlayStore, aplikasi Instagram di iPhone, aplikasi mobile banking.

---

### 4. UI/UX Designer (Perancang Tampilan & Pengalaman Pengguna)
- **💡 Analogi**: *Arsitek & Psikolog Tata Ruang* — Merancang tata letak bangunan agar indah dipandang mata (*UI*) dan nyaman digunakan tanpa membingungkan penghuni (*UX*).
- **Tugas Utama**:
  - **UI (User Interface)**: Memilih warna, ikon, tipografi huruf, dan visual tombol.
  - **UX (User Experience)**: Meriset kebiasaan pengguna, membuat alur navigasi dari buka aplikasi hingga pembayaran berhasil tanpa hambatan (*frictionless*).
- **Tools**: Figma, Adobe XD, FigJam, Miro, Whimsical.

---

### 5. Game Developer (Pengembang Gim Interaktif)
- **💡 Analogi**: *Sutradara & Dalang Dunia Virtual* — Menciptakan dunia khayalan lengkap dengan hukum fisika, kecerdasan buatan musuh, dan jalan cerita.
- **Tugas Utama**: Memprogram gameplay mekanik karakter, sistem skor, kecerdasan musuh (AI), animasi visual, dan interaksi kontroler.
- **Bahasa & Tools**: Unity (C#), Unreal Engine (C++), Godot (GDScript), Blender (3D Modeling).
- **Contoh Hasil Karya**: Game Mobile Legends, Free Fire, gim edukasi 2D/3D.

---

### 6. Data Engineer & Data Scientist (Pakar Pengolah Data)
- **💡 Analogi**: *Ahli Tambang Minyak & Analis Intelijen* — Menggali jutaan barel data mentah dari transaksi aplikasi, lalu menyulingnya menjadi informasi berharga.
- **Tugas Utama**: Membangun saluran pipa data (*data pipeline*), membersihkan data kotor, dan membuat algoritma rekomendasi.
- **Bahasa & Tools**: Python, R, SQL, Apache Spark, Pandas, Tableau, TensorFlow.
- **Contoh Hasil Karya**: Algoritma "FYP" TikTok, sistem rekomendasi film Netflix, prediksi tren belanja online.

---

### 7. DevOps & Cloud Engineer (Insinyur Otomasi & Infrastruktur)
- **💡 Analogi**: *Pengatur Lalu Lintas Udara & Tim Pemelihara Listrik Kota* — Memastikan server aplikasi tidak pernah padam (*zero downtime*) meskipun diserbu jutaan pengguna secara bersamaan.
- **Tugas Utama**: Mengelola server cloud, mengotomatiskan proses rilis kode (*CI/CD pipeline*), memonitor performa server, dan menjaga keamanan siber (*security*).
- **Tools**: Linux, Docker, Kubernetes, AWS, Google Cloud, GitHub Actions, Nginx.

---

### 8. QA Engineer / Software Tester (Penguji Kualitas Perangkat Lunak)
- **💡 Analogi**: *Inspektur Kelaikan Jalan & Detektif Cacat Pabrik* — Mencari setiap celah kesalahan atau bug sebelum produk diluncurkan ke masyarakat umum.
- **Tugas Utama**: Menjalankan skenario pengujian manual maupun otomatis (*automation testing*), mendokumentasikan bug, dan memastikan aplikasi tidak mudah crash.
- **Tools**: Selenium, Cypress, JMeter, Postman, Jest, Jira.

## 🔄 Studi Kasus: Bagaimana Tim Bekerja Sama?

Kalian ingin membuat fitur **"Beli Tiket Konser Online"**:
1. **Product Manager**: Mendefinisikan kebutuhan fitur dan target waktu rilis.
2. **UI/UX Designer**: Merancang alur pemilihan kursi dan tampilan tiket digital di Figma.
3. **Frontend / Mobile Dev**: Mengubah rancangan Figma menjadi layar antarmuka di HP/Web.
4. **Backend Developer**: Menghubungkan tombol "Bayar" ke sistem bank dan memotong kuota kursi di database secara realtime.
5. **QA Tester**: Mencoba membeli tiket dengan berbagai skenario ekstrem (misal: koneksi putus tiba-tiba, saldo tidak cukup) untuk memastikan tidak ada bug.
6. **DevOps Engineer**: Menyiapkan server berkekuatan tinggi agar website tidak jebol saat *war ticket* 100.000 pengunjung serentak.
